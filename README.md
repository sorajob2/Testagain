# Container Return Booking System

ระบบเว็บสำหรับจองคิวคืนตู้คอนเทนเนอร์ พัฒนาขึ้นเพื่อช่วยให้ผู้ใช้งานสามารถเลือกวันและช่วงเวลาสำหรับนำตู้คอนเทนเนอร์มาคืนได้สะดวกมากขึ้น

ระบบสามารถบันทึกข้อมูลบริษัท ผู้ติดต่อ ทะเบียนรถ หมายเลขตู้ สายเรือ ประเภทตู้ รวมถึงวันและเวลาที่ต้องการจอง โดยมีการเชื่อมต่อกับ LINE LIFF เพื่อรองรับการใช้งานผ่าน LINE

## Technology

* HTML
* CSS
* JavaScript
* LINE LIFF
* Vercel
